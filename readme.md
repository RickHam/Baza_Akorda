Instalacija:

1. Skini dist folder. (ili cijeli file). Pritiskom na Code i download zip.
2. extractaj
3. pokreni .exe u dist folderu

u dist folderu se nalazi moj songs.json koji sprema akorde za pjesme.
Ako želiš započeti s praznom bazom, samo izbriši songs.json.

Debug:
Ako je json izbrisan i crasha aplikacija (nebi se trebalo dogoditi):
napravi prazan songs.json i pokreni ponovo aplikaciju.
